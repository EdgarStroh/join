# Join

Join is a task management web application inspired by the Kanban system.  
It lets users create, organize, and assign tasks using intuitive drag-and-drop functionality.  

## ✨ Features

- User registration and login
- Create, edit, and delete tasks
- Drag-and-drop task organization
- Assign tasks to team members and categories
- Save and manage contact information
- Responsive design for desktop and mobile

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `index.html` file in your browser.
3. Register a user and start managing your tasks!

## 🧩 Technology Stack

- HTML, CSS, JavaScript
- Modular and clean code structure
- Local storage and dynamic DOM rendering

## 📱 Interface

Join is fully responsive and works seamlessly on both desktop and mobile devices.
